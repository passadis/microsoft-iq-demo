# Support

This repository is a community demo and is provided without a support
guarantee.

- For deployment and setup guidance, see [SETUP.md](SETUP.md) and the
  component guides linked from the [README](README.md).
- For a reproducible defect, open an issue using the bug report form.
- For a proposed improvement, use the feature request form.
- For a possible security vulnerability, follow [SECURITY.md](SECURITY.md);
  do not report it publicly.

When asking for help, include the relevant steps and sanitized error output.
Do not post credentials, access tokens, private customer data, or other
sensitive information.
