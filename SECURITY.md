# Security Policy

## Supported versions

Security fixes are considered for the latest version on the default branch.
This project is a demonstration and does not provide a production support
commitment.

## Reporting a vulnerability

Please report suspected vulnerabilities privately. If GitHub's private
vulnerability reporting is enabled for this repository, use it. Otherwise,
contact the repository owner through
[their GitHub profile](https://github.com/passadis).

Do not disclose vulnerability details in a public issue or pull request. Please
include enough information to understand and reproduce the concern, while
avoiding real credentials, customer data, or other sensitive information.
There is no guaranteed response or remediation timeline.

This repository contains Azure demo configuration and synthetic data. Never
commit secrets, production credentials, or real personal data.
